# Unistroke Recognition Demo

A desktop companion application for
[`unistroke_recognition`](https://github.com/ygharsallah/unistroke_recognition).

This project is built with [Bevy](https://bevyengine.org/) and provides an
interactive demo for drawing and recognizing unistroke gestures.

## Demo

Download the latest Windows executable from the
[Releases](https://github.com/ygharsallah/unistroke_recognition_demo/releases) page.

## Related Repository

The recognition algorithm is implemented in the main repository:
